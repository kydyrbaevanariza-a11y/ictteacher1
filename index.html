1. Негізгі ұғымдар

Цикл

Белгілі бір шарт орындалғанша бірнеше рет қайталанатын әрекеттер жиынтығы.

Итерация

Цикл денесінің бір рет орындалуы.

Инкремент

Айнымалы мәнін арттыру, мысалы i++.

For циклі қалай жұмыс істейді?

1) Айнымалыны инициализациялау → 2) шартты тексеру → 3) цикл денесін орындау → 4) айнымалыны өзгерту → қайтадан шартты тексеру.

for (int i = 1; i <= 3; i++) { // цикл денесі print(i); }

Шарт true болса, цикл денесі орындалады. Шарт false болса, цикл тоқтайды.

2. Trace Table — циклді қадамдап бақылау

Мысал: for (int i = 1; i <= 3; i++)

ИтерацияШартiНәтиже
11 ≤ 3 — Иә11
22 ≤ 3 — Иә22
33 ≤ 3 — Иә33
44 ≤ 3 — Жоқ4Цикл аяқталды

Интерактивті симулятор

Бастапқы мәні: 1, шарт: i ≤ 5, қадам: +1.

Бастау үшін батырманы басыңыз.

3. Түсінікті тексеру

1. for (int i = 10; i > 0; i--) циклі неше рет орындалады?

2. for (int x = 0; x < 10; x += 2) цикліндегі соңғы мән қандай?

4. Практикалық тапсырмалар

1-тапсырма

1-ден 10-ға дейінгі сандарды экранға шығаратын цикл жазыңыз.

2-тапсырма

Берілген бүтін сандар массивінің барлық элементтерінің қосындысын есептейтін цикл жазыңыз.

3-тапсырма

Тізімдегі тек жұп сандарды экранға шығаратын цикл жазыңыз. if қолдануға болады.

5. Қателерді түзету

Мәселе 1: Цикл i < 5 шартымен 1,2,3,4 мәндерін ғана қосады. 5 саны есепке алынбайды. Дұрыс нұсқа: i <= 5 немесе i < 6.

Мәселе 2: i = 0 болып, шарт i < 10, ал өзгеріс i-- болса, цикл тоқтамайды: 0, -1, -2... Бұл — Infinite loop.

Мәселе 3: 3 элементі бар массивтің индекстері 0,1,2. i <= 3 қолданылса, arr[3] шақырылады. Дұрысы — i < 3.
